# postquality.com

The public home of [Post Quality Manager](https://github.com/vincentheimann/post-quality-manager): a static site served by GitHub Pages at https://postquality.com (Jekyll, `minima` theme, no build step).

- `index.md`, `pricing.md`, `docs.md`: the front, pricing and documentation pages.
- `privacy.md`, `terms.md`, `refund.md`, `support.md`: the policies. Their source of truth is `docs/policies/` in the plugin repository; change them there first, then copy here.
- `CNAME`: the custom domain.

A proper landing page (Astro) replaces the front page once real users have bought the plugin (plugin backlog story 50).
